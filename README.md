# Flores Amarillas & Kuromi para Yami 💛

Detalle virtual interactivo en 3D (WebGL / Three.js) de girasoles amarillos y Kuromi para celebrar el día de las flores amarillas.

## 🌻 Características
- Escena 3D interactiva en Three.js con rotación orbital de 360°.
- Kuromi animada con efecto *billboard* (siempre mira al observador).
- Ramo 3D con cúpula de girasoles amarillos brillantes y caritas tiernas.
- Frases románticas flotantes en órbita 3D.
- Modal con carta y dedicatoria personalizada para Yami.
- Lluvia interactiva de pétalos y corazones.

## 🚀 Cómo ejecutarlo
Abre directamente `index.html` en cualquier navegador web moderno o sírvelo mediante un servidor local (XAMPP/Apache o `python -m http.server`).
